Part 1 · Installation

Install SpiderTV Test

These steps work with Downloader by AFTVnews on supported Android TV and Fire TV devices.

Step 1

Get the Downloader app

  1. From your TV home screen, open the app store.
  2. Search for Downloader by AFTVnews (orange app icon).
  3. Choose Install, then Open.

ONN 4K: use Google Play. Fire TV: use the Amazon Appstore if Downloader is offered on your device.

Step 2

Enter the SpiderTV code

  1. Open Downloader.
  2. Select its URL / short-code box.
  3. Enter 2240676, then choose Go.
  4. Let the APK download.
Downloader code
2240676
Step 3

Install and open SpiderTV

  1. When the file finishes downloading, choose Install.
  2. If your TV blocks it, open Settings on the prompt and allow Downloader to Install unknown apps.
  3. Return to the installer, choose Install, then Open.
Only allow the install from Downloader when you are using the SpiderTV code given here. The exact permission wording varies by device.
Part 2 · Account login

Connect your account

The account information goes into the SpiderTV app on the television—not into this website.

Step 4

Sign in on the SpiderTV screen

  1. Open SpiderTV Test.
  2. Leave Standard selected unless you were told to use a different connection.
  3. Leave the pre-filled Server address as it is for Standard.
  4. Enter your Username and Password exactly as provided.
  5. Select Connect.

If you were specifically given a custom service address, select Custom and enter that address before connecting.

Tip: username and password are case-sensitive. The “Show password” switch can help you check what you typed.
Step 5

Wait for your categories to load

  1. Once connected, look for TV, Movies, and Shows.
  2. Move with the remote arrows.
  3. Select TV to enter Live TV and the channel guide.

The first channel catalog load can take longer than later launches. You should not have to type your account details every time you open the app.

Part 3 · TV guide

Add your EPG guide

EPG means Electronic Program Guide. It's the information that shows what's on each channel and when it starts.

Step 6

Open EPG settings

  1. From the SpiderTV menu, choose Settings.
  2. Select EPG / TV guide.
  3. Choose EPG sources.

If your IPTV provider already supplies program information, the provider EPG switch may be all you need. If you received a separate EPG URL, continue to Step 7.

Step 7

Enter your separate EPG link

  1. Choose Add EPG URL.
  2. Enter a name, such as My TV Guide.
  3. Enter the full XMLTV / EPG URL you were given, with no extra spaces.
  4. Leave Enabled turned on.
  5. Select Save.

Saving the URL should start an EPG update. If nothing happens, return to EPG settings and choose Update EPG.

The EPG URL may contain a private token. Do not post it in a public chat or support screenshot.
Step 8

Let the guide finish its first update

  1. Return to EPG / TV guide and open Update EPG if needed.
  2. Watch the update status as programs download and save.
  3. When finished, select Open TV guide or return to TV.
  4. For normal use, you can set the update interval to 12 hours.

The first import can take several minutes with a large guide. In testing, a guide with about 400,000 programs took approximately eight minutes. Later launches should reuse saved guide information.

Don't choose Clear EPG unless you're intentionally deleting your guide.
Missing program information on some channels? The IPTV channel may not match an EPG listing automatically. In the TV guide, long-press that channel and choose Assign EPG to match it to a listing from your downloaded source.

Help

Common questions

Downloader says the app cannot be installed.

Check that Downloader is allowed to install unknown apps. Then try the install again. Some devices restrict sideloading entirely. Do not uninstall a working SpiderTV installation to troubleshoot this test app.

The username or password is rejected.

Check spelling, uppercase/lowercase, and the Standard/Custom connection choice. Ask the person who supplied your account to confirm it is active. Do not put credentials on this website.

Channels work, but the TV guide is blank.

Confirm the EPG source is enabled and the first EPG update has finished. If the guide still has gaps, try Assign EPG for a particular channel. Some provider lists do not supply their own guide.

Can I use a single connection for Multiview?

Some providers limit simultaneous streams. If you have one connection, adding another video may fail. Check your account's connection allowance before testing Multiview.

Do I need to reinstall the app after every update?

The test app should update in place when the package name, signing certificate and version code remain compatible. Install the latest build using the same Downloader code when your tester invites you to update.
